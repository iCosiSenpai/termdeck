# Termdeck brand mark

The Termdeck icon combines a terminal prompt with three stacked profile cards. It is original project artwork and uses the same cyan, mint, violet, off-white, and near-black language as the Control Center.

- `termdeck-icon.png` is the 512×512 transparent master used by GitHub and project pages.
- `termdeck-icon-128.png` is a compact transparent raster for terminal graphics integrations and small UI surfaces.
- `termdeck-mark.txt` is the universal Unicode representation rendered by the Termdeck Control Center. It requires no terminal-specific graphics protocol.

The raster artwork was generated with OpenAI's built-in image generation tool and refined locally for transparency. Final prompt:

> Create a compact original emblem for Termdeck, combining a modern terminal window with a small stacked deck of profile cards. The front terminal panel contains only a simple geometric prompt chevron and cursor block, with no letters or words. Use a crisp, premium, flat vector-style construction that remains readable at 32 pixels. Use near-black, electric cyan, off-white, mint, and restrained violet. No text or watermark.
